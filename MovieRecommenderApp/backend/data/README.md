Copy the two files from your data-processing notebook into this folder:

- `movies.csv`
- `movie_feature_dictionary.json`

The CSV must include the movie display fields (`id`, `title`, `overview`,
`poster_path`) and the model fields (`adult`, `softcore`, `video`,
`original_language_code`, `popularity`, `vote_average`, `vote_count`,
`release_year`, and the `genre_...` columns).

User feedback CSV files, imported profiles, and skipped-movie lists are created automatically in `backend/data/users/`.
